# Petroleum Refinery Inventory & Production System

This SQL project simulates a **petroleum refinery's inventory and production system**, using MySQL Workbench. It was designed to demonstrate relational database design, data insertion, and powerful querying for insights related to production, raw materials, inventory, and supply.

## 📁 Project Structure

The project consists of:

- `refinery_schema.sql` — SQL script to create all necessary tables
- `refinery_data.sql` — Sample data inserts for all tables
- `refinery_queries.sql` — A collection of analytical queries

## 📦 Tables Created

1. **Products** – Finished goods like petrol, diesel, kerosene, and cooking gas
2. **RawMaterials** – Main inputs such as crude oil and additives
3. **Suppliers** – Suppliers of raw materials
4. **Inventory** – Stock levels for each product
5. **Production** – Records of daily production and material usage
6. **Supply** – Records of raw material supplies

## 🧪 Sample Data

- Sample products: Petrol, Diesel, Kerosene, Cooking Gas
- Raw materials: Crude Oil, Additives
- Suppliers: NNPC Ltd, Chevron Nigeria, TotalEnergies
- Inventory and supply values simulate real operational scenarios

## 📊 Example Queries

- List of products and their stock levels
- Total inventory value
- Top products by stock quantity
- Total crude oil used in production
- Products produced today
- Raw materials supplied and suppliers involved
- Average production by product
- Products not produced today
